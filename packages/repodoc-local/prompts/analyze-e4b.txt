## Instructions

1. Analyse the code carefully. Prioritise bugs that cause incorrect behaviour, data loss, security risk, or crashes.
2. For each bug, produce:

   - `line` — approximate line number (integer, or null if not applicable)
   - `description` — what the bug is and why it matters (≤ 80 words)
